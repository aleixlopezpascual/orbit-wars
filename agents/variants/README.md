# Versioned Agent Variants

This folder contains historical and experimental Orbit Wars agents that were previously in the repository root.

- `v26_*` to `v30_*`: older baseline and submission-era snapshots
- `v31_*` / `v32_*`: ablation candidates
- `v34_*`: newer experimental candidates

Use these files with `run_validation.py` or `scripts/run_ablation_gate.sh`.
